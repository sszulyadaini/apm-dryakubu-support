# Dr Yakubu Birni Da Karkara Support Group — APM

Simple responsive site scaffold using Tailwind CSS (CDN) and APM color variables.

Quick start

1. Open `index.html` in your browser.
2. The project uses the Tailwind CDN for layout utilities; no build step required.

Files

- index.html — Main page
- assets/css/styles.css — Custom color variables and small utilities
- assets/js/main.js — Mobile menu + header behavior

Colors used (APM):

- Primary Green: #008751 / #009933
- Royal Blue: #0055A5 / #0066CC
- Crisp White: #FFFFFF
